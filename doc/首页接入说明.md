# 萌宠拼豆首页

沿用 Cocos Creator 3.8.8。打开 `assets/scenes/RowPrototype.scene`，停止旧预览后重新预览，默认进入首页。

首页使用 `docs/bead_home_ui/bead_home_ui/assets` 的独立背景、Logo、小猫展示图、嫩芽、按钮和设置素材；没有使用整张首页截图充当界面。原始 PNG 保留，复制到 `assets/resources/ui-home`。副标题、关卡名、按钮文字、页脚使用独立系统字体 Label，关卡名读取 `PICTURE_NAME`。Logo、展示图仅用于首页，不覆盖现有关卡矩阵。

- 开始拼豆：进入现有游戏。按下缩小至 0.96，松开恢复；移出、取消触摸、切后台时不触发开始。
- 设置：可开关音效；与游戏调试面板共用音量参数。
- 返回首页：游戏设置底部新增入口。停止自动模式、释放发射、暂停模拟，保留当前排、在途豆和拼图进度。再次开始后继续准备与归位，需要主动重新开启自动模式。
- 我的作品：当前没有作品管理功能，按素材说明暂时隐藏，避免无响应入口。
- 安全区：864×1536、SHOW_ALL 沿用现有画布策略，主要触控远离边缘，长关卡名在限定宽度内缩小。超长屏、刘海屏仍需真机确认。

实现位于 `assets/scripts/HomeScreen.ts`，入口接在 `RowPrototype.ts`。重新导入素材运行 `python tools/import-home-assets.py`。

已验证：TypeScript 类型检查；首页层级与独立素材加载；按压、取消、开始与返回；首页不推进模拟；音量开关；保留进度；游戏 2993 帧展示代码回归；17 个行状态机场景；50×50 全图与自动模式的正常、慢速和 2 倍射速测试。

复现：`node tools/test-home.cjs`、`node tools/test-row-render.cjs`、`node tools/test-row.cjs`、`node tools/test-picture.cjs`、`node tools/test-auto.cjs`。

布局对照：运行 `python tools/render-home-ui.py`，查看 `temp/home-ui/comparison.png`。这是生产场景代码的 CPU 布局合成，不是 Creator 截图。素材包说明自身也是参考图重绘拆分，所以 Logo 字形、按钮厚度、背景花叶与参考图存在素材级差异；未擅自重画。

仍待编辑器/手机验证：Creator 实际图片导入与中文字体、GPU 渲染、按钮触摸与多点触摸、切后台恢复、长屏安全区。当前会话原生捕获工具不可用，不能宣称真机视觉验收通过。
