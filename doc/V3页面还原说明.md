# V3 页面接入

## 一键全自动

进度条下方右侧新增「全自动」按钮。开启后变为「停止自动」，自动完成当前行选色、最多5夹分批装填、上膛、发射、换夹及逐排推进，直到2500颗全部落位。自动模式复用原状态机和动作时长，不跳过动画，不直接涂色或预填目标。

再次点击立即停止新增发射，正在补位和在途的豆子继续完成；可以从现有弹药、枪膛和进度继续开启自动。自动运行时锁定手动选色与发射，停止按钮保持可点。打开设置/射速菜单、切后台、重置本排/整图都会停止自动，回来后需主动再次开启。整图完成时自动关闭。

验证：`node tools/test-auto.cjs` 无需直接调用装填或按住操作，分别在1×射速、2×射速、0.5×动作慢放下自动完成2500颗、49次换行，检查唯一目标、5槽上限、库存守恒和一次性完成；停止/继续、在途落位、后台暂停、完成后禁止重新空射、重置取消均通过。生产UI代码检查覆盖一键启动、跨行持续自动、停止、菜单暂停和后台恢复。类型与原有回归测试通过。真实编辑器/手机体验仍需实际预览。

射速控件放在枪头与枪体接缝处，显示「射速 1×」，显示层高于枪头和枪身以盖住接缝；点击后在上方展开0.5×/1×/2×菜单。其触摸区与右侧发射按钮分开。

## 当前装填选择规则

每行开始或重置后，色豆选择根据该行需求重新计算。需要且尚未装填的颜色显示原色、允许点击；本行没有、已装填、正在按住发射、队列满或后台暂停时，相关颜色用真实灰度材质和灰色文字显示，并关闭触摸节点。事件入口再次检查状态，防止同一帧重复点选。松手后仅恢复尚未装填的颜色；换行重新开放该行可用颜色。

按最新澄清，要求铺满的是下方选色栏，而不是给图案每排补齐颜色。选色栏固定铺满614设计像素，全部五种颜色始终显示，不需要的颜色保留为灰色占位且不可点击。已移除边缘补色，整张图恢复与 `PictureData.ts` 完全一致的自然配色，总格数仍为2500。

新增验证已通过：16组单行测试、整图1×/0.5×完整打完、2472帧UI检查；覆盖灰度禁用、缺色禁用、同一帧重复点选、发射期间锁定、松手恢复以及换行重新着色。类型检查通过，尚未取得真实Creator运行截图。

## 操作

点颜色装夹，按住右侧「发射」，松手停止新增发射。在途豆继续落位，完成当前整排并退夹后再进入下一排。数量为0的颜色不装夹，同色每排只装一次。

首夹从选色条进入待发槽，再滑入横向供豆仓；空夹退出后下一个接入。待发夹依FIFO前移补空位，不复制库存。容器内显示实际数量的豆子，不用固定装饰豆。发射点是独立枪头下的 `FirePoint`，发射时读取其世界坐标并换算到飞豆层。

枪身和横仓不参与后坐，只有绿色枪头后坐。射速按钮展开 **0.5× / 1× / 2×** 菜单，仅改变发射间隔和补豆时间，已飞出豆子的飞行、落位时间不变。打开菜单或设置立即解除按住状态。

点右上齿轮打开设置，可调节全部原有动作参数、音量、动作慢放，并使用「重置本排」「重置整图」。**动作慢放**作用于统一模拟时钟，与外面的射速倍率分开。默认保留每秒6颗的基础手感，枪头初始后坐4设计像素。音效仍为先前的临时 WAV。
