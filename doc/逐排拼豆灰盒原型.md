## 启动

1. 用 Creator **3.8.8** 打开本项目，等待 assets 导入完成。
2. 双击 `assets/scenes/RowPrototype.scene`，预览**当前场景**。组件已挂在 Canvas，无须手动拖拽绑定。
3. 依次点黄、红、蓝（顺序也可以任意），等待首颗上膛，然后按住「按住发射」。至少装一夹就能开始。
4. 完成后点「重置本排」。重置保留当前调试参数和速度，清除本排全部动作、目标预占、在途豆和状态。

项目已生成 Web Mobile 输出目录 `build/web-mobile`，不要直接用 file:// 打开。可在项目终端运行：

```powershell
python -m http.server 7458 --bind 127.0.0.1 --directory build/web-mobile
```

然后在浏览器打开 `http://127.0.0.1:7458`。也可使用 Creator 的构建发布面板构建 Web Mobile，选择本场景为首场景、方向 Portrait。

可复用构建配置：`tools/build-prototype.json`。命令行示例（引擎路径按本机调整）：

```powershell
& 'D:/ProgramData/cocos/editors/Creator/3.8.8/CocosCreator.exe' --project "$PWD" --build "configPath=$PWD/tools/build-prototype.json"
```

## 画面与参数入口

- 顶排固定为：黄、黄、红、黄、蓝、红、黄、红、蓝、黄、红。编号 01 黄、02 红、03 蓝。
- 三个选色按钮分别生成 5 / 4 / 2 颗的弹夹；重复点同色只显示提示，不生成新夹。
- 五个开放槽位保留队列位置；接入枪位后释放原槽位。弹夹的每颗豆都有实际数量的几何实体。
- 枪位显示容器数量、当前弹夹剩余数量；透明枪膛显示豆子颜色和「途中 / 已上膛」。总剩余弹药包含上膛途中及枪膛中的未发射豆。
- 「在途」从发射起计，包含击中嵌入过程，嵌入结束才计入「已归位」。
- 下方始终可见调试面板，点击 − / + 调整；左下速度按钮在 1× 与 0.5× 间切换。

| 参数 | 初值 | 面板范围 |
| --- | --- | --- |
| 发射频率 | 6 颗/秒 | 3–10 |
| 单颗补位及上膛 | 100 ms | 25–600 ms |
| 装夹 | 300 ms | 100–1000 ms |
| 自动换夹总时间 | 300 ms | 150–1500 ms |
| 飞行 | 250 ms | 50–1000 ms |
| 击中归位 | 150 ms | 50–600 ms |
| 后坐 | 7 px | 0–20 px |
| 回弹 | 1× | 0–2× |
| 音效音量 | 50% | 0–100% |

每个动作开始时锁定自身时长，调整只影响后续动作；速度切换立即影响整个模拟时钟。自动换夹包含「退夹 + 下一夹接入 + 首颗上膛」，默认各 100 ms。若上膛参数大于换夹总时长，则优先完整上膛，并给退夹和接入各保留至少 20 ms，因此实际换夹会延长。队列中弹夹尚未装入完成时，也会等待其装夹结束。

首夹还要经历从等待槽接入枪位的短路径。射击必须同时满足：仍按住、节拍已到、上膛完成、有同色合法空目标。慢补位不会积攒欠发次数，也不会瞬间补射。松手和拖出发射按钮停止新增发射；正在进行的上膛、飞行、归位和换夹继续完成。切后台会暂停统一时钟并自动松手，回来后需重新按住。

## 音效与替换

`assets/resources/audio/` 中的六个 WAV 均为本次生成的**临时合成音效**：`lock` 装夹/卡扣、`feed` 上膛、`shot` 圆润啵声、`hit` 双音归位、`eject` 轻退夹、`complete` 完成。没有真实枪声。替换同名 WAV 即可，或修改 `RowPrototype.sound()` 的映射。运行时使用 4 个轮转音轨，播放前停掉该轨旧声音；源文件留有音量余量，面板控制总音量。

## 实现入口

- `assets/scripts/RowModel.ts`：独立状态机、统一模拟时钟、目标预占、弹药守恒和一次性结算。
- `assets/scripts/RowPrototype.ts`：Cocos 几何绘制、实体豆的路径/补位/压缩回弹、触控、音频与调参。
- `tools/test-row.cjs`：无第三方测试依赖，编译纯状态机后验证。运行 `node tools/test-row.cjs`；其他电脑可通过环境变量 `COCOS_TSC` 指向 Creator 自带的 `typescript/lib/tsc.js`。
- `tools/create-prototype-assets.py`：重建场景、稳定 UUID 元数据及临时音效，通常不必运行；如果手动编辑了场景或替换音效，不要再次运行，以免覆盖这些修改。

所有动画按状态时间推导，不使用残留的 tween、setTimeout 或 schedule 回调。重置直接丢弃旧局的实体和预占；豆子 ID 不复用。归位有状态门禁，退夹与完成均只结算一次。

## 实际验证与待验

**已通过自动化逻辑验证**（10 组，40,172 次守恒/唯一性检查）：

- 5 黄 4 红 2 蓝完整打完，覆盖三色全部六种点击顺序；同色目标按从左到右绑定。
- 发射时唯一预占；弹药只在射出时减少；容器内 + 枪膛内 = 当前夹剩余。
- 中途松手：不新增射击，在途归位与已开始补位继续；松手后可继续装夹。
- 换夹时松手：下一夹准备完成，不自动发射。
- 只装蓝色一夹：2 颗可打完；最后一颗仍留在枪膛时容器已空；之后只退夹一次，不空射。
- 快速重复点色、按住时点其他颜色。
- 多个动作阶段重置后不产生旧局归位或完成，新一局仍可完整打完。
- 后台暂停的模型时钟冻结、松手与恢复后不自动射击。
- 0.5 倍同时减慢射击节奏与动作；400 ms 慢上膛限制 10 颗/秒设定，不补射。
- 18,000 步随机装填、按住/松手、重置、速度切换。

**类型检查**：使用本机 Creator 自带 TypeScript，对项目运行 `tsc --noEmit -p tsconfig.json --skipLibCheck` 通过。`skipLibCheck` 只跳过 Creator 自带声明文件中的内部类型问题，项目脚本仍接受检查。
