本PRD定义Q版动物逐排拼豆小游戏V1.0，供策划、美术、音效和Cocos开发使用。核心体验是点选色块，把彩豆装入弹夹队列，按住固定豆枪自动逐颗填入当前排同色格。空夹自动弹出、下一夹自动接入，逐排完成动物图案。无需滑动、瞄准或手动逐色换夹。

版本：V1.0 MVP，2026年10月27日修订。项目暂称“动物拼豆”，图片关卡名示例为“小鸡的花园”，非最终产品名称。移动端竖屏，使用Cocos Creator；具体编辑器版本以本地项目为准，发布平台与支持设备待定。本文动画时间、速度和视觉参数均为首版调试值。本次修订替代旧版滑动扫射规则，以本版正文为开发依据。

# 1 产品定位与版本目标

一句话玩法：点选彩豆装入弹夹，按住发射，让小方块自动击中归位，逐排拼出漂亮治愈的Q版动物。

面向喜欢可爱动物、整理填色和轻操作的休闲玩家。通过装填的卡合感、连续发射的节奏、击中后嵌入孔位的触感，以及图案逐步完整的成就感形成体验。

V1.0验证三个问题：新玩家是否能独立完成装夹与第一排；装填、连续射豆和空夹退出是否令人愿意重复；逐排装夹是否流畅而不繁琐。先验证核心体验，不以商业化、长线留存或大规模关卡作为验收目标。

# 2 版本范围

必须实现：1个完整小鸡关卡及独立单排测试场景、弱化底图、逐排激活、颜色编号、点选装夹、5个开放装填位、按住自动发射、自动换夹、精确计数、击中归位反馈、换排、关卡完成、基础引导、设置与本地进度恢复。兔子、橘猫作为后续扩展，本版不要求同时制作3个正式关卡。

不纳入本版：倒计时、生命值、失败惩罚、付费和广告、金币道具、养成装修、排行榜、联网账号、分享奖励、关卡编辑器和真实复杂物理模拟。

弹夹内可视小方块用于表达颜色、材质和消耗变化，精确数量以数字为准。孔位与弹药由数据判定，不使用随机散射或不稳定物理碰撞决定入位；每颗飞行豆仍须有独立、可见的飞行与命中过程。

# 3 核心规则

## 3.1 图案与排推进

关卡由固定网格表示，每个有效格预先指定一种颜色，空值为无需填充区域。小鸡与花园中的花、草可纳入有效图案；不能将所有动物轮廓外区域一律排除。未来区域只显示很淡的轮廓与浅色预览，让玩家认出动物但看不清完整成品细节。当前排完整显示主色浅色底与数字，不能只显示局部。已完成格显示紧密整齐、轻微圆角和浅浮雕的小方块，减少深缝、强高光和厚颗粒感。

从最下方有有效孔位的一排开始，向上逐排推进。一排可以包含不相邻的有效孔，空白不占豆数；整排为空时自动跳过，不播放空排完成效果。

当前排完成之前，不允许填其他排。新排激活后重新选择颜色并装豆，不自动沿用上一排颜色。当前排内颜色顺序自由，不强制按编号发射。

## 3.2 颜色与编号

采用“淡色底＋数字编号”，不在每个孔中写颜色汉字。编号与颜色在同一关内固定；跨关优先沿用同一套色板映射。下方按钮固定位置，当前排不用的颜色置灰，不动态重排。

选色区采用紧凑相连的小色块，每块显示固定颜色编号，颜色较多可分两排，布局由数据生成。预留约10色的排版能力，但V1.0每排最多5种有效颜色。颜色状态为：可装填、已入队或正在发射、该色完成、当前排不用。已入队加小勾或顺序标，禁止重复入队；该色全部归位后显示完成勾；当前排不用的色块弱化且不可点击。已入队与已完成需通过边框、标记或文字区分，不能只靠颜色深浅。

## 3.3 示例

当前排11个有效格，共5黄、4红、2蓝。玩家依次点击黄、红、蓝，生成黄5颗、红4颗、蓝2颗的三个弹夹。按住发射：先射5颗黄豆，黄夹用完弹出，红夹自动接入射4颗，再接蓝夹射2颗。每颗自动进入当前排同色空格。11格全部归位且无在途豆、换夹动作已结束，才出现下一排。玩家也可只先装黄夹，发射完松手，再装红夹与蓝夹继续。颜色入队顺序自由。

5黄、4红、2蓝只是数量例子，不代表三种颜色必须各自连续排列；孔位顺序由动物图案决定。

# 4 操作与命中判定

## 4.1 点选装夹与弹夹队列

新排进入等待装填状态，显示“点选彩豆，装入弹夹”。点击可用色块时，先预留一个空槽并锁定该颜色的入队资格，再播放色块或彩豆向弹夹飞入、弹夹卡合的动画。弹夹携带该颜色在当前排尚未填入的全部数量。第一个弹夹就绪后进入枪膛，其余按点击先后等待。

5个开放装填位包含枪内正在使用的弹夹及等待弹夹，总占用不得超过5；装填中的预约槽同样占容量。锁定位仅作预留，V1.0不可解锁、不触发广告。每排最多5种颜色，不要求玩家填满5槽。建议等待队列按小号顺序标记表示先后；中央枪身可保留，两侧槽位若均用于等待，必须按固定编号取夹，空夹另向下侧短距离弹出消隐，不占等待槽。回收动画不能与可装填位混淆。待发顺序和颜色编号使用不同位置与样式。

允许在未按住发射时继续装夹；V1.0不支持拖动排序、移除弹夹或主动跳过当前夹。已入队颜色不可重复点击。连续点击不同可用颜色时，按触摸确认顺序立即预留槽位和队列序号，再串行播放短装填动画，不能悄悄吞掉有效点击。满槽或锁定位点击仅轻提示。按住发射期间禁用选色输入；第二触点不得装夹。

至少一夹完成装填且首夹已就绪即可按住“按住发射”按钮，按下立即尝试首发，之后按间隔连续发射。枪身固定，枪口可轻微朝向目标作表现，但玩家不控制方向。按钮周围枪身下半部可扩展为同一触摸区，不侵入选色和弹夹区。移出有效触摸区、松手或触摸取消均停止新增发射；重新进入不会自动恢复，需重新按下。

## 4.2 自动目标与换夹

发射时从当前排该弹夹颜色的未填且未预占有效格中，按列从左至右选择一个目标。目标不受枪身横坐标或手指位置影响。同色格可以不连续。无有效目标则不得发射或扣数，不会跨到未来排；数量不一致视为开发异常，停止发射并记录。

当前夹最后一颗射出后即可启动空夹退出，下一夹自动移入并上膛，不必等待该色在途豆全部落定。正在按住时换夹完成后自动续射；若已松手，只完成换夹准备，不新增发射。等待队列为空但有尚在装填的已预约弹夹时等待就绪；若已无任何已装或预约弹夹且当前排仍未满，则退出发射状态并提示继续装填，清除本次按住状态。

豆子沿清楚、短促的上行直线或轻弧线自动飞往已绑定目标，跨列移动由轨迹表现完成。飞行豆渲染于底板上层，不被已完成格挡住，不能穿透效果变成物理碰撞。发射后不得改变目标，轨迹与落点须准确衔接。

## 4.3 数量与在途处理

每个孔使用空置、预占、已填三种状态。发射时原子地预占唯一孔位并扣除一颗可发射豆，归位后将孔置为已填。预占期间不能对同一孔重复发射。

每夹可发射数量等于其未消耗弹药，发射成功预占时减1；在途数量等于预占格数。枪窗和弹夹显示颜色编号与剩余颗数，如“1号 · 剩5颗”。数值变0后允许空夹退出，但该颜色只有在全部目标归位后才显示完成勾。重复预占、重复归位回调和重复出夹均须防重处理。

换排条件为当前排所有有效格已填、在途数量为0、该排所有弹夹均已退空且没有装填或换夹动作进行中。达到条件只触发一次排完成效果，清空队列与按住状态，刷新下一排颜色需求；不自动装填或跨排连射。

# 5 装豆与命中反馈

上膛具有明确机械卡合感，但材质偏圆润塑料、木质与软弹。避免尖锐枪声、火焰、弹壳和强烈枪械后坐。

| 阶段 | 必须看见的动作 | 声音方向 | 初始节奏 |
| - | - | - | - |
| 点选装夹 | 小色块或彩豆飞入空槽，形成透明无色弹夹，内部方块与选色一致 | 轻触与小方块碰撞 | 每夹约250至350毫秒 |
| 上膛 | 弹夹进入枪膛、卡扣闭合、首豆前推、枪窗显示当前颜色 | 短促柔和的咔嗒 | 首次就绪约150至250毫秒 |
| 发射 | 单颗实体小方块飞出，枪口轻微后坐 | 圆润的啵 | 初始每秒6至8颗 |
| 飞行 | 自动飞向绑定目标，短轨迹迅速消失 | 不叠加长哨音 | 约180至300毫秒 |
| 击中 | 小方块短暂轻压，目标格边缘小光圈 | 柔和的嗒 | 约40至60毫秒 |
| 归位 | 轻回弹后嵌入，编号消失，呈现最终色与浅浮雕 | 与击中紧密衔接的卡合音 | 击中加归位共120至180毫秒 |
| 空夹退出与接夹 | 空夹轻弹退出消隐，下一夹顺滑接入 | 轻巧咔哒，声音不压过射击 | 两动作合计约250至350毫秒 |
| 颜色完成 | 该色最后一颗归位，色块显示完成状态 | 轻提示，可不单独播放 | 不阻塞操作 |
| 整排完成 | 整排柔光，下一排完整淡入 | 简短悦耳完成音 | 约250至350毫秒 |
| 整图完成 | 完整图案充分显色，轻微整体呼吸，不再遮罩 | 简短完成旋律 | 展示约800至1200毫秒后出按钮 |

重点：豆子必须经历“飞到、碰一下、回弹、嵌入”，不能只以孔位变色代替。整屏不随每颗豆震动；粒子和光圈不遮住编号。击中与归位可制作成一条合成音效，不要求两条独立播放。

若最后一色同时完成整排，只播放整排完成提示；若同时完成整关，以整关提示为主，避免三种提示音叠加。暂停或静音立即停止相关声音。

基础功能不依赖手机振动。若目标平台支持，可加默认关闭的轻触觉反馈，且不得每颗连续震动。

# 6 页面与流程

## 6.1 进入与游戏页

首次启动直接进入第一关；已有未完成进度则恢复该关。本版无需独立复杂首页。

顶部是普通字体的图片名称、总进度与设置，不为每张图单独制作标题图片。主区域展示完整拼豆图，当前排两端用简洁括号标记，不厚描每格。背景使用干净的米白或浅薄荷渐变，避免花草细节影响主图。图案下方是紧凑连续的小色块选色区，靠下安排，可扩展两排；底部为固定豆枪、弹夹槽与枪身上的“按住发射”按钮，枪窗可见当前小方块、编号及余量。保留底部安全区，手指不遮挡枪窗、枪口和目标排。选色、槽位、发射三个触摸区域不得重叠。

总进度＝已归位有效孔数／全图有效孔总数，预占孔不计入已完成。可附加“第3排／共8排”，只计算非空排。竖屏布局适配不同长宽比，手指不得持续遮挡当前目标排。

## 6.2 新手引导

首排依次引导：“点选彩豆，装入弹夹”“还可以继续装入其他颜色”“按住发射，自动填色”。引导随操作完成消失，不代装豆。首次空夹退出可轻提示“下一夹自动接上”。队列空而当前排未满时提示“继续装入剩余颜色”；当前排完成后提示新排可装填。只对首次关键操作给引导，不反复遮挡画面。

## 6.3 完成与设置

完成后保留完整动物图，显示“拼好啦”，提供再玩一次。只有确实配置了下一关时才显示下一关；单关版本不得出现不可用入口。完成状态保存一次，不重复结算。

设置提供音效开关、可选背景音乐开关、继续游戏和重新开始本关。重开需一次确认，取消保持进度。设置弹出时暂停游戏，返回后不自动恢复连射，必须重新按住操作区。

| 内容 | 规格 | 目的 |
| - | - | - |
| 单排开发测试 | 11格，5黄4红2蓝；顺序示例1、1、2、1、3、2、1、2、3、1、2 | 验证自由入队、精确数量与自动换夹；与正式关卡色板独立 |
| 首个正式关卡 | 小鸡的花园，完整颜色矩阵与最终配色图；每排不超过5色 | 验证完整一局、弱预览到完整成品和手机操作 |
| 后续扩展 | 兔子、橘猫 | 不属于本次V1.0必交范围 |

正式图不强制沿用旧版8至12列网格。可按确认美术图采用约30至40列的精细网格，但须检查手机上当前排编号和命中反馈可读性；最终行列数以经过校验的关卡配置为准，不凭效果图估算硬编码。

网格是包围尺寸，不要求每格都有豆。每只动物须在目标网格下保持可辨认，避免依赖未被豆子表达的细线画出五官。首关初期少色短排，后续再增加混色，不要求每排用满所有颜色。

每排各色数量由矩阵实时计算，不另行维护易冲突的弹药表。优先避免连续多排都需装5夹且每夹只有1颗，减少重复点选负担。完整关卡时长由填格数量、射速、装夹和换夹耗时共同决定，应实测调整，不以理论射速宣称时长。超过5色的排在配置校验阶段拒绝，V1.0不依靠锁位解锁来完成。

# 8 状态与异常处理

主状态为等待装填、就绪、发射中、自动换夹、换排中、完成、暂停；装填队列另有预约与动画状态。就绪且存在有效按住触点时发射。自动换夹可保留按住意图但禁止新射出；换排、暂停和队列耗尽清除按住意图。排完成只由归位与队列状态共同驱动，不能由某个动画回调单独推断。

| 情况 | 处理要求 |
| - | - |
| 松手、移出发射区或系统取消触摸 | 停止新增发射，在途豆继续归位；不因手指横移而改变枪位 |
| 多指操作 | 仅首次有效触点控制发射，第二触点不能同时选色 |
| 重复点击同色 | 当前排同色只生成一个弹夹 |
| 快速点击不同色 | 按确认先后预留槽和队列，动画顺序执行，不超容量 |
| 点击不用的颜色或锁定位 | 不装夹、不扣数量，轻提示即可 |
| 当前夹用完且下一夹存在 | 自动退出并接入，按住状态下继续 |
| 松手发生在换夹期间 | 换夹准备可完成，禁止自动续射 |
| 队列耗尽但排未满 | 停射清除触点，等待继续装填 |
| 最后一颗在途 | 不提前完成排或关卡 |
| 设置或切后台 | 暂停动画声音与计时，恢复后需重新按住 |
| 重启 | 已归位结果保留，未归位豆重新计入剩余，重新装夹 |
| 配置无有效格、缺颜色或单排超过5色 | 校验失败，用户侧给无法加载与重试入口；不进入死局 |

单次暂停保留内存中的在途状态；进程重启仅恢复已归位结果，不恢复半颗在途豆。每次归位更新存档，恢复后按剩余空孔重新计算数量；不能同时保存未归位的扣数造成永久少豆。

# 9 数据与资源需求

## 9.1 关卡与存档数据

关卡数据至少包含关卡ID、配置版本、动物名称、行列数、颜色映射、孔位矩阵和底图资源。矩阵统一按从上至下存储，空值代表轮廓外，颜色ID代表有效孔；运行时按行号递减向上推进。

颜色映射包含固定ID、显示编号、颜色值及豆子资源。图案矩阵是有效孔和颜色数量的唯一权威来源；底图应与矩阵一致。

存档包含配置版本、关卡ID、已填孔集合、已完成关卡和音效设置。当前排、数量、总进度均可由已填孔重新计算。恢复时回到未装豆状态。配置版本不兼容时重置受影响的关卡并提示，不套用旧孔位。

## 9.2 美术资源

# 11 开发顺序与试玩验证

第一步做单排灰盒：固定11格的5黄4红2蓝样例，完成色块点击、5位队列、按住自动发射、目标预占、空夹退出、自动接夹和数量核对。

第二步做单排手感：接入分层豆枪和弹夹、装夹上膛、自动飞行、击中压缩、嵌入及对应音效。调试连续按住的节奏，不扩充无关系统。

第三步做完整小鸡关卡：校验矩阵与配色、未来排弱化、整排数字、逐排推进、存档与结算。随后按最终UI接入正式素材并适配手机，完成本PRD验收表。扩充新动物在本关通过后进行。

试玩建议邀请5名未见过规则的玩家，不口头讲解，记录第一排是否独立完成、是否理解弹夹先后、是否误以为必须装满5槽、是否知道队列打空后还可装填。询问最舒服和最想跳过的环节，观察点选准确率与整局用时。

建议本地记录装夹次数、每排颜色数、装填及换夹等待时长、连续发射时长、主动松手、退出位置与关卡用时。等待占比过大时优先缩短装填和换夹动画，不能用取消实体飞行或瞬间整排填满代替优化。本版无需搭建埋点后台。

开发使用Cocos Creator和TypeScript，具体编辑器版本跟随现有项目，不擅自升级。最终名称、发布平台、设备清单和正式小鸡图案矩阵待实际素材交接确认。不得把玩法改回滑动瞄准，不得自动替玩家选色装夹，不得跨排自由填豆或一键瞬间填满。
